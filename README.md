# ระบบติดตาม Antenna บนเสา Tower — AWN

Web Application สำหรับติดตามจำนวน Antenna (ANT AWN / Microwave / ANT DTAC) ที่ AWN ติดตั้งบนเสาโทรคมนาคมของ บมจ.โทรคมนาคมแห่งชาติ
บันทึกรื้อถอน/ติดตั้งรายเดือน นำเข้าไฟล์ Excel รายเดือน ออกรายงาน Excel รูปแบบเดิม และปิดเดือน — ใช้ได้ทั้งคอมพิวเตอร์และมือถือ

- **หน้าเว็บ** — HTML/CSS/JavaScript ล้วน ไม่ต้อง build เก็บบน GitHub และเปิดผ่าน GitHub Pages
- **ฐานข้อมูล + ล็อกอิน** — Supabase (PostgreSQL + Auth + Storage + Realtime)
- **ความปลอดภัย** — สิทธิ์ทุกอย่างบังคับที่ฐานข้อมูลด้วย Row Level Security ไม่ใช่แค่ซ่อนปุ่มบนหน้าเว็บ

---

## โครงสร้างไฟล์

```
index.html              หน้าเว็บ
css/style.css           หน้าตา (รองรับมือถือ)
js/app.js               การทำงานทั้งหมด
js/config.js            ← ใส่ URL และคีย์ของ Supabase ที่นี่
supabase/schema.sql     โครงสร้างฐานข้อมูล สิทธิ์ และ Trigger (รันใน Supabase)
data-upload/sites.json  ข้อมูลตั้งต้น 10,909 สถานี (ม.ค.–ก.ย. 69) — ห้าม commit ขึ้น GitHub
```

> `data-upload/` อยู่ใน `.gitignore` แล้ว ข้อมูลสถานีจริงจะถูกเก็บใน Supabase Storage แบบไม่เปิดสาธารณะ
> ดังนั้น repository บน GitHub ไม่มีข้อมูลของหน่วยงาน ตั้งเป็น Public ได้

## ติดตั้งครั้งแรก (ประมาณ 20 นาที)

### 1. สร้างโปรเจกต์ Supabase
1. สมัคร/เข้าสู่ระบบที่ https://supabase.com → **New project**
   - Region แนะนำ **Southeast Asia (Singapore)**
   - ตั้งรหัสผ่านฐานข้อมูลและเก็บไว้
2. เมนู **SQL Editor** → **New query** → เปิดไฟล์ `supabase/schema.sql` คัดลอกทั้งหมดมาวาง → **Run**
   (รันซ้ำได้ ไม่ทำให้ข้อมูลหาย)
3. เมนู **Project Settings → API Keys** คัดลอก
   - **Project URL**
   - **Publishable key** (`sb_publishable_...`) — ถ้าโปรเจกต์ยังมีแต่ `anon` key ให้กด *Create new API keys* หรือใช้ anon key ไปก่อนก็ได้
   - ⚠️ ห้ามใช้ **Secret key / service_role key** ในหน้าเว็บ

### 2. ใส่ค่าใน `js/config.js`
```js
export const SUPABASE_URL = "https://abcdefgh.supabase.co";
export const SUPABASE_KEY = "sb_publishable_xxxxxxxx";
```

### 3. ขึ้น GitHub และเปิด GitHub Pages
1. สร้าง repository ใหม่บน GitHub (เช่น `awn-ant-tracker`)
2. อัปโหลดไฟล์ทั้งหมด **ยกเว้นโฟลเดอร์ `data-upload/`**
   (ใช้ GitHub Desktop, `git push` หรือปุ่ม *Add file → Upload files* บนเว็บ)
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save
4. รอ 1–2 นาที จะได้ลิงก์ เช่น `https://<ชื่อบัญชี>.github.io/awn-ant-tracker/`

> GitHub Pages ฟรีใช้กับ repository แบบ Public — ถ้าต้องการ Private ให้ใช้ GitHub แบบเสียเงิน
> หรือเชื่อม repository เดียวกันกับ Cloudflare Pages / Netlify / Vercel (ฟรี และรองรับ Private repo)

### 4. ตั้งค่าล็อกอินใน Supabase
**Authentication → URL Configuration**
- **Site URL** = ลิงก์ GitHub Pages ของคุณ
- **Redirect URLs** → เพิ่มลิงก์เดียวกัน (ใช้กับลิงก์ยืนยันอีเมลและลืมรหัสผ่าน)

**Authentication → Sign In / Providers → Email**
- ระบบอีเมลในตัวของ Supabase ส่งได้จำนวนจำกัดต่อชั่วโมง ถ้ามีผู้ใช้หลายคน แนะนำตั้ง **Custom SMTP** (เมนู Authentication → Emails → SMTP Settings)
- หรือปิด **Confirm email** ถ้าไม่ต้องการให้ยืนยันอีเมล (ผู้ดูแลยังต้องอนุมัติสิทธิ์ทุกคนอยู่ดี)

### 5. เปิดใช้งาน
1. เปิดลิงก์เว็บ → **สมัครใช้งาน** — **บัญชีแรกของระบบจะเป็นผู้ดูแล (admin) อัตโนมัติ**
2. เข้าสู่ระบบ → ระบบจะขอไฟล์ข้อมูลตั้งต้น → เลือก `data-upload/sites.json`
3. ส่งลิงก์ให้ทีมสมัคร → เข้าแท็บ **ผู้ดูแลระบบ** แล้วกำหนดสิทธิ์ให้แต่ละคน

## ระดับสิทธิ์

| สิทธิ์ | ดูข้อมูล / ดาวน์โหลดรายงาน | บันทึก / นำเข้าไฟล์ | ปิด–เปิดเดือน | จัดการผู้ใช้ / ข้อมูลตั้งต้น / ดูประวัติแก้ไข |
|---|:-:|:-:|:-:|:-:|
| รออนุมัติ | – | – | – | – |
| ผู้ดู | ✓ | – | – | – |
| ผู้บันทึก | ✓ | ✓ | – | – |
| ผู้ดูแล | ✓ | ✓ | ✓ | ✓ |

- ผู้สมัครใหม่ทุกคนเริ่มที่ “รออนุมัติ” และยังไม่เห็นข้อมูล
- ระบบไม่ยอมให้ลดสิทธิ์ผู้ดูแลคนสุดท้าย
- เดือนที่ปิดแล้วแก้ไขไม่ได้ (ฐานข้อมูลปฏิเสธ) จนกว่าผู้ดูแลจะเปิดเดือนอีกครั้ง
- ทุกการเพิ่ม/แก้/ลบ ถูกบันทึกในตาราง `audit_log` (ดูได้ในแท็บผู้ดูแลระบบ)

## การใช้งานแต่ละเดือน

1. **แท็บ “บันทึกรื้อถอน/ติดตั้ง”**
   - นำเข้าไฟล์ Excel รายเดือนรูปแบบเดิม (เช่น `10. Tower ที่ใช้บริการติดตั้ง ANT (ต.ค. 69).xlsx`) — ระบบอ่านเดือนจากหัวคอลัมน์ `Total ANT (…)`, เทียบกับเดือนก่อน, สร้างรายการให้ทุกสถานี และตรวจยอดแยกภาคเทียบกับชีต “สรุป”
   - หรือบันทึกทีละสถานี / วางหลายรายการจาก Excel
2. **แท็บ “ตรวจสอบข้อมูล”** — ดูจุดที่ตัวเลขไม่สอดคล้อง
3. **แท็บ “ออกรายงาน Excel”** — รายงานประจำเดือน, รายไตรมาส (V.xx-x), สรุปรายปี, รายการบันทึกของเดือน
4. **ปิดเดือน** (ผู้ดูแล) — ยอดคงเหลือจะเป็นยอดตั้งต้นของเดือนถัดไป

ทุกเครื่องที่เปิดอยู่จะเห็นการเปลี่ยนแปลงทันที (Realtime)

## ข้อควรรู้

- **Supabase แพ็กเกจฟรี** อาจพักโปรเจกต์อัตโนมัติเมื่อไม่มีการใช้งานต่อเนื่องประมาณ 1 สัปดาห์ (กดเปิดคืนได้ใน Dashboard) และไม่มีการสำรองข้อมูลที่ดาวน์โหลดเองได้ — ตรวจเงื่อนไขล่าสุดที่หน้า Pricing ของ Supabase หากใช้งานจริงระยะยาวควรพิจารณาแพ็กเกจ Pro
- **สำรองข้อมูลเอง**: ทุกสิ้นเดือนดาวน์โหลดรายงานประจำเดือน + รายการบันทึกเก็บไว้ หรือใช้ Supabase Dashboard → Table Editor → `changes` → Export CSV
- **อัปเดตข้อมูลตั้งต้น**: แท็บผู้ดูแลระบบ → อัปโหลด `sites.json` ใหม่ (ไม่ลบรายการที่บันทึกไว้)
- **Available Space** ในรายงานไตรมาสเป็นค่าประมาณ: ความจุเสา (Available Space + ANT ณ ก.ค. 69) ลบ ANT ของเดือนนั้น
- ไลบรารีที่โหลดจาก CDN: `@supabase/supabase-js` (jsDelivr), `exceljs` และ `xlsx` (cdnjs) — เครื่องผู้ใช้ต้องเข้าถึงอินเทอร์เน็ตได้

## แก้ปัญหาเบื้องต้น

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ขึ้น “ยังไม่ได้ตั้งค่า Supabase” | ยังไม่ได้แก้ `js/config.js` หรือ GitHub Pages ยังไม่อัปเดต (รอ 1–2 นาที แล้วรีเฟรช) |
| สมัครแล้วไม่ได้รับอีเมล | ตรวจ Spam / ตั้ง Custom SMTP / ปิด Confirm email |
| กดลิงก์ในอีเมลแล้วไปหน้า localhost | ตั้ง Site URL และ Redirect URLs ในข้อ 4 |
| เข้าได้แต่ขึ้น “รอผู้ดูแลอนุมัติ” | ผู้ดูแลต้องกำหนดสิทธิ์ในแท็บผู้ดูแลระบบ |

| ผู้ใช้คนแรกไม่ได้เป็น admin | รันใน SQL Editor: `update public.profiles set role='admin' where email='อีเมลของคุณ';` |
